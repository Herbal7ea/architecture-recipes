# Architecture Recipes

A tool for developers to discover and apply proven architectural patterns.

## What it does

- **Browse** a catalog of architectural recipes with search and category filters
- **Explore** each recipe's tradeoffs, use cases, and visual diagrams
- **Apply** step-by-step with code examples and file structure guidance
- **Export** completed recipes as Markdown for your team's docs

## Tech Stack

- React 19 + TypeScript
- Tailwind CSS v4
- React Router v7
- Lucide icons

## Getting Started

```bash
npm install
npm run dev
```

## Status

Proof of concept — mock data, no backend. Demonstrates the core discovery → detail → apply → summary flow.
